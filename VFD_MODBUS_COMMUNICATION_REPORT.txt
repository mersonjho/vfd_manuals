## UNIVERSAL MODBUS RTU STANDARDS (All Drives)

### Standard Configuration Found Across All Manufacturers

```
Default Settings:
├─ Baud Rate: 9600 bps
├─ Parity: 8N1 (8 data bits, No parity, 1 stop bit)
├─ Transmission: Half-Duplex RS485
├─ Slave ID Range: 1-247
├─ Error Check: CRC-16 checksum
└─ Frame Format: Standard Modbus RTU

Communication Command Format:
├─ Slave Address: 1 byte
├─ Function Code: 1 byte (0x03, 0x04, 0x10, etc.)
├─ Data: 2+ bytes (addresses and values)
├─ CRC: 2 bytes (checksum)
└─ Frame End: After CRC

Standard Modbus Function Codes:
├─ 0x03: Read Holding Registers
├─ 0x04: Read Input Registers
├─ 0x10: Write Multiple Holding Registers
└─ 0x01/0x02/0x05: Coil operations
```

### RS485 Physical Layer Standard

```
Pin Layout:
├─ A+ (or A): Non-inverting (positive) signal
├─ B- (or B): Inverting (negative) signal  
├─ GND: Ground/Reference
└─ Shield: Cable shield (connect to GND)

Termination:
├─ Resistor: 120 ohm ± 5%
├─ Power: 0.25W (1/4W minimum)
├─ Placement: Both ends of transmission line
└─ Note: Essential for lengths > 500m

Cable Specification:
├─ Type: Shielded twisted pair
├─ Impedance: 120 ohm
├─ Gauge: 22 or 24 AWG typical
└─ Maximum Length: 1000m (at 9600 bps)
```

### Common Register Address Patterns


## KEY TECHNICAL NOTES

### Baud Rate Selection
- **9600 bps**: Default, most compatible, lowest noise sensitivity
- **19200+ bps**: Higher speed, requires better quality cable and shielding
- **38400 bps**: Maximum for most industrial applications
- **115200 bps**: Highest speed, requires premium cable and careful installation

### Parity Significance
- **8N1**: Standard for Modbus RTU (no parity bit)
- **Even Parity**: Adds redundancy, rare for RTU (typical for ASCII)
- **Odd Parity**: Alternative redundancy option

### Termination Resistor Importance
- **Required for:** Proper signal reflection prevention
- **Standard Value:** 120 ohm (±5%)
- **Power Rating:** 0.25W minimum (1/4W)
- **Placement:** Both ends of transmission line for long runs
- **Missing Effect:** Signal reflections, communication errors, intermittent failures

### Cable Length Considerations
- **< 500m:** Single termination at far end acceptable
- **500-1000m:** Dual termination at both ends recommended
- **> 1000m:** Consider repeaters or fiber optics (not standard RS485)
